## Description
Close runtime-capture gaps in the MAIN-world page hooks (`src/content/page-hooks.ts`): URL key correctness, CSSOM stylesheet injection visibility, FontFace API loads, and canvas-generated assets.

## Acceptance Criteria
- [x] fetch and XHR hook events post absolute URLs (resolved against `location.href`), so hook-keyed assets/bodies merge with webRequest records for relative-URL requests.
- [x] `CSSStyleSheet.prototype.insertRule` / `replace` / `replaceSync` and the `adoptedStyleSheets` setters notify the content script (via postMessage event) so CSS-in-JS injected url() assets get scanned without DOM mutations.
- [x] `new FontFace(family, "url(...)")` source URLs are posted as font asset events.
- [x] `canvas.toBlob` / `canvas.toDataURL` / `OffscreenCanvas.convertToBlob` outputs are captured as runtime-generated assets, bounded per page so per-frame canvas churn cannot flood capture.
- [x] All new hooks are non-destructive (original behavior preserved, errors swallowed) and size-capped consistent with existing MAX_BODY_BYTES posture.
