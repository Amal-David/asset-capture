## Description
Close DOM/CSS scanning and pre-inspection-history gaps in the isolated-world content script (`src/content/content-script.ts`, `src/content/asset-detection.ts`).

## Acceptance Criteria
- [x] CSS rule scanning extracts url() references from the full rule text (custom properties like `--bg: url(...)`, mask/shape/src and any future url()-bearing property), not just a fixed property allowlist.
- [x] CSSOM-change notifications from the page hook mark styles dirty and trigger a stylesheet re-scan.
- [x] On PAGE_RESCAN (inspection start), the full `performance.getEntriesByType("resource")` history is sent as an asset batch, so network assets loaded before the panel opened are recovered (metadata).
- [x] The resource-timing buffer is raised (and `resourcetimingbufferfull` handled) so long-lived pages do not silently stop recording history at 250 entries.
- [x] A bounded replay buffer of recent page-hook metadata events (blob / data-url / fetch / xhr) is kept pre-inspection and flushed on PAGE_RESCAN, so blob:/data: assets created before the panel opened are recovered.
- [x] `og:image` / `twitter:image` (and similar meta image references) are captured during DOM scans.
