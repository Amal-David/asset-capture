## Description
Close network-side capture gaps in the service worker (`src/background/service-worker.ts`) and classifier (`src/shared/classify.ts`).

## Acceptance Criteria
- [x] HLS/DASH manifests detected from network capture (webRequest / page-hook events) by MIME or URL path produce MediaRecords, not just DOM-discovered `.m3u8`/`.mpd` URLs.
- [x] Deep capture enables CDP Network with explicit buffer sizing (`maxTotalBufferSize` / `maxResourceBufferSize`) so large or slow response bodies are not evicted before `Network.getResponseBody`.
- [x] `classifyAsset` maps `main_frame`/`sub_frame` resource types to `document`.
- [x] Unit tests cover the new classifier mapping and manifest-detection logic.
